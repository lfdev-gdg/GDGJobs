# Módulo de ML e IA

Este diretório será usado para treinamento, embeddings, recomendações e pipelines de IA do GDG Jobs.

## Objetivo

- Separar a lógica de processamento inteligente do restante da aplicação
- Manter modelos, pipelines e scripts de experimento em um lugar explícito
- Preparar a evolução para a camada de recomendação da V3

## Estrutura esperada

- pipelines/: scripts de extração, limpeza e transformação
- models/: artefatos ou checkpoints de modelos
- notebooks/: experimentos analíticos
