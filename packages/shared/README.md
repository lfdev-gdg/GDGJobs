# Shared Package

Este package centraliza tipos, schemas e regras compartilhadas entre frontend, backend e ML.

## Objetivo

- Evitar duplicação de interfaces entre módulos
- Criar contratos claros para jobs, perfis e eventos do sistema
- Facilitar manutenção de código e onboarding
