# Guia de Contribuição

Este guia orienta como colaborar com o GDG Jobs de forma organizada e acolhedora.

## Boas práticas

- Siga a convenção de código em TypeScript
- Mantenha a estrutura modular do projeto
- Evite implementar lógica de negócio fora do módulo adequado
- Documente mudanças importantes
- Use comentários `TODO` para indicar continuidade de implementação

## Fluxo sugerido

1. Crie uma branch para sua tarefa
2. Mantenha o escopo restrito ao que foi pedido
3. Verifique lint e type check
4. Abra PR com descrição clara

## Áreas de contribuição

- Frontend
- Backend / API
- Banco de dados
- Design system
- IA / recomendações
- Documentação

## Observação

Este projeto ainda está em fase de scaffolding e continuará evoluindo por etapas de produto.
